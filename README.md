## 📌 About

This is the source code of my personal portfolio website. It presents my services, skills and selected projects to clients and employers, with a fast, mobile-first design.

**Services showcased**

- 🤖 AI agent development & AI automation
- 📈 Digital marketing & SEO
- 🛒 eBay dropshipping & marketplace management
- 🌐 Frontend development (React, TypeScript)

## ✨ Features

- Floating **WhatsApp chat launcher** so visitors can contact me in one tap
- Fully responsive design with refined mobile navigation and touch targets
- Hero, services and project sections with horizontal project filters
- Clean, modern UI built with reusable components

## 🛠️ Tech stack

- **React + TypeScript** with **Vite**
- Client / server / shared project structure (`client/`, `server/`, `shared/`)
- Component library setup (shadcn-style `components.json`)
- Package management with **pnpm**

## 🚀 Run it locally

```bash
pnpm install
pnpm dev
```

## 📂 Project structure

```
hasnaat-anjum-portfolio/

├── server/        # Server code
├── shared/        # Code shared between client and server
├── package.json
└── vite.config.ts
```
